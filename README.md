# My configuration

An accretion of configuration files.

## Install

Clone the repository into `~/.ljc`:

```sh
git clone https://codeberg.org/ljc/dotfiles.git ~/.ljc
```

Refer to the *README* file in each subfolder to set up the rest:

- [bash](bash/README.md)
- [git](git/README.md)
- [macos](macos/README.md)
- [python](python/README.md)
- [readline](readline/README.md)
- [ruby](ruby/README.md)
- [tmux](tmux/README.md)

## See also

- [dotvim](https://codeberg.org/ljc/dotvim) (Vim and NeoVim)
